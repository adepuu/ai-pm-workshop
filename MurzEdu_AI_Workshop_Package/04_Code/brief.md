# Project Brief — v2 Onboarding Flow

**Goal:** Ship a redesigned onboarding flow for our mobile app that lifts
day-7 activation from 38% to 50% within one quarter.

**Scope**
- New 3-step signup (email, profile, first action)
- In-app checklist with progress
- Welcome email sequence (3 emails)

**Constraints**
- Team: 2 engineers, 1 designer, 1 PM (you)
- Deadline: 6 weeks
- Must pass security review before launch
- No customer PII in any third-party analytics

**Open questions**
- Do we A/B test against the current flow?
- Which vendor for the email sequence?
